# P:E Einkaufsplaner

Wochen-Einkaufsplaner mit Protein:Energie-Verhältnis, Makro- und Mikronährstoff-Auswertung.
Eine einzelne HTML-Datei ohne Server und ohne externe Abhängigkeiten ausser den Schriften.

**Live:** https://fims-medizin.github.io/pe-einkaufsplaner/

Die Seite ist absichtlich für Suchmaschinen gesperrt (`robots.txt` und `noindex`).
Sie dient dem Testen ausserhalb des Kurses; im Kurs läuft sie als HTML5-Paket in LearnWorlds.

## Quellen

- Nährwerte: Schweizer Nährwertdatenbank des BLV (naehrwertdaten.ch)
- Selen, Kupfer, Mangan, Omega-3, Aminosäuren: USDA FoodData Central, SR Legacy
- Bor, Chrom, Molybdän, Silizium: Literaturtabellen, in der Seite mit `≈` als Schätzwert markiert
- Referenzwerte: D-A-CH sowie «Mikronährstoffbedarf im Sport» (FIMS)
- Kohlenhydrate nach Trainingsumfang: ACSM / AND / DC 2016, DGE 2019
- P:E-Konzept: Ted Naiman

Projektdateien, Vorlagen und Anleitung liegen bei FIMS in OneDrive, nicht in diesem Repo.
